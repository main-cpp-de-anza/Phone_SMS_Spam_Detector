# GitHub Accent Design

## Goal

Make the GitHub navigation button and footer repository link feel deliberate within the warm parchment and terracotta visual system.

## Navbar button

The GitHub button uses a charcoal ink fill, warm off-white text, and the existing pill shape. On hover it lifts slightly, becomes marginally darker, and gains a restrained terracotta shadow. Keyboard focus retains the existing accessible focus ring.

## Footer link

The repository link uses charcoal text and a subtle terracotta underline. On hover, the text shifts to the terracotta accent while retaining the underline, making it visibly interactive without competing with the footer copy.

## Scope

Only CSS selectors for `.nav-github` and `.footer a` will change. HTML, link destinations, layout, and unrelated controls remain unchanged.
