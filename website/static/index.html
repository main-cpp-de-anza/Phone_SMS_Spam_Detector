Concept 1

Hard-Coded Keyword Matching (Naive)

The simplest baseline: keep a list of dirty words. If any bad word appears in the message, scream SPAM immediately.

The Logic & Why It Fails

O(N) String Search

Why People Start With It

  • Takes 5 lines of Python code.
  • Zero machine learning or math training needed.
  • Instantly blocks obvious lazy spammers.

Why It Breaks in Real Life

  • Zero context: Blocks friend saying "Are you free for lunch?" because of word "free".
  • Easy to trick: Spammer writes "fr33" or "w!nner" and bypasses rule completely.
  • Human must manually update dictionary forever.
The Math / Logic Rule
Verdict = SPAM  if  (any w ∈ BannedWords in text)  else  HAM

Binary boolean check. No shades of gray. 1 accidental bad word kills whole message.

Concept 2

Heuristic Point Scoring (Apache SpamAssassin Method)

Instead of a binary on/off switch, treat spam like a credit score. Words add or subtract points.

The Tug-of-War Scoring Model

Weighted Sum + Threshold

Every suspicious word adds positive points (+). Every normal, conversational word subtracts points (-). Normal words cancel out accidental bad words so real conversations don't get blocked.

Suspicious Words Add Points (+)

  • "account blocked": +4.0 pts
  • "kyc" / "pan card": +3.5 pts
  • "stuck at transit": +3.5 pts
  • "bit.ly" / "tinyurl": +2.5 pts
  • "SHOUTING (ALL CAPS)": +2.0 pts

Friendly Words Subtract Points (-)

  • "homework" / "graduated": -3.0 pts
  • "haha" / "lol": -3.0 pts
  • "lunch" / "dinner": -2.5 pts
  • "tomorrow": -2.0 pts
  • "mom" / "dad": -2.0 pts
The Mathematical Formula
Total Score = Σ (Points of matching phrases) + [2.0 if AllCaps > 40%]
Verdict = SPAM  if  Total Score ≥ 2.0  else  HAM

Example: "Are you free for lunch tomorrow? Haha"
free (+1.5) - lunch (2.5) - tomorrow (2.0) - haha (3.0) = -6.0 pts (HAM!). Safe words save innocent text from false alarms.

Concept 3

TF-IDF Vector Math & Linear Support Vector Machine

Computers can't read English. Machine Learning converts text into numerical coordinates (vectors), then draws an optimal line separating spam and normal messages.

From Text to High-Dimensional Geometry

TF-IDF + LinearSVC Hyperplane

1. Term Frequency (TF)

Counts how many times word appears in this text. Uses Sublinear TF:

TF = 1 + log(count)  if count > 0

Stops scammers from repeating "FREE" 50 times to hack model.

2. Inverse Document Frequency (IDF)

Measures how rare word is across 67,664 messages:

IDF(t) = log( (1 + N) / (1 + df(t)) ) + 1

Boring words like "the" get wiped out. Rare words like "kyc" get massive boost.

The LinearSVC Decision Function
f(x) = (w · x) + b = Σ (w_i × x_i) + b

• x = message vector (coordinates in 40,000-dimensional space).
• w = weights learned by computer during training.
• If f(x) > 0, message lands on SPAM side of hyperplane.
• If f(x) < 0, message lands on HAM side. Distance from plane gives confidence score.

Our Machine Learning Pipeline

Data Engineering
Step 1 • Cleaning

Domain Token Replacement (Regex Normalizer)

  • Replaces URLs like http://claim-free.biz or bit.ly/3x with [url].
  • Replaces cash amounts like $500, £1,000, 150p with [money].
  • Replaces phone and shortcodes like 08000930705 or 88066 with [phone].
  • Replaces numbers, times, and dates with [number].
  • Forces lower-case and strips junk spacing.
Raw text: "URGENT! Call 09061743811 from landline. Win £1000 cash or gift! Claim at http://gift.ly"
Cleaned: "urgent! call [phone] from landline. win [money] cash or gift! claim at [url]"
Step 2 • Tokenizing

Character Subword n-grams (3 to 5 characters)

  • Chops text into 3, 4, and 5 letter overlapping slices inside word borders.
  • Spam trick "fr33" produces "fr3", "r33", "fr33".
  • Spam trick "w!nner" produces "w!n", "!nn", "nne", "ner".
  • Matches the root character pattern even if word is misspelled or novel.
  • Works with emojis, slang, concatenated phrases ("freemsg"), and weird symbols.
Input word: "fr33"
Slices generated: [" fr", "fr3", "r33", "33 ", " fr3", "fr33", "r33 ", " fr33 "]
Step 3 • Weighting

Sublinear Term Frequency Scaling (TF-IDF)

  • Applies logarithmic dampening formula: weight = 1 + log(tf) when count > 0.
  • 1 occurrence → weight 1.0.
  • 10 occurrences → weight 2.3 (not 10.0).
  • 100 occurrences → weight 3.0 (not 100.0).
  • Repeated spam terms get diminishing returns; maintains message context balance.
Formula: w = 1 + ln(count)  |  TF(count=20) = 1 + ln(20) ≈ 3.00 (instead of 20.0)
Step 4 • Validation

Stratified 5-Fold Cross Validation

  • Full dataset has 67,664 SMS messages (74% Ham, 26% Spam).
  • "Stratified" keeps exact 74% / 26% balance inside every fold.
  • Splits into 5 equal parts: 4 parts (80%) train, 1 part (20%) tests out-of-sample.
  • Rotates 5 times until all 67,664 texts are tested on unseen models.
  • Delivers verified 98.84% accuracy, 95.25% F1 score, only 51 missed spam out of 17,737.
Split: Fold 1 (20% test) • Fold 2 (20% test) • Fold 3 (20% test) • Fold 4 (20% test) • Fold 5 (20% test) → Average: 98.84% Accuracy
